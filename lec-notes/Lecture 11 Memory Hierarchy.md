# 内存层次结构 - 学习笔记

## 整体思路与逻辑

本PPT围绕**内存层次结构**展开，逻辑清晰分为三个核心部分：

1. **存储技术与趋势**：介绍各类存储设备的技术特性与性能差异
2. **局部性原理**：解释程序访问模式的内在规律，为缓存提供理论基础  
3. **缓存机制**：展示如何利用局部性构建高效的内存层次结构

这三部分形成完整的因果链：**存储性能差距 → 局部性原理 → 缓存解决方案**

## 第一章：存储技术与趋势

### 整体思路
从最快的SRAM到最慢的磁盘，系统介绍各类存储技术的特性、性能差异和发展趋势，揭示CPU与内存之间的性能鸿沟。

#### 1.1 随机存取存储器(RAM)

**SRAM vs DRAM对比**

| 特性 | SRAM | DRAM |
|------|------|------|
| 晶体管数/位 | 4或6 | 1 |
| 访问时间 | 1X | 10X |
| 需要刷新 | 否 | 是 |
| 需要错误检测 | 可能 | 是 |
| 成本 | 100X | 1X |
| 应用 | 缓存内存 | 主内存、帧缓冲区 |

**关键点**：
- SRAM：更快、更贵、用于缓存
- DRAM：较慢、便宜、用于主内存

#### 1.2 非易失性存储器

**存储器类型演进**：
- ROM：生产时编程
- PROM：可编程一次
- EPROM：可批量擦除（UV、X射线）
- EEPROM：电擦除能力
- Flash：部分（块级）擦除能力，约10万次擦写寿命

**应用场景**：
- 固件程序存储
- 固态硬盘
- 磁盘缓存

#### 1.3 传统总线结构与内存事务

**内存读事务流程**：
1. CPU将地址A放到内存总线
2. 主内存读取A，检索字x并放到总线
3. CPU从总线读取字x到寄存器

**内存写事务流程**：
1. CPU放置地址A，内存等待数据
2. CPU放置数据字y到总线
3. 内存读取数据字y并存储到地址A

#### 1.4 磁盘存储技术

**磁盘结构**：
- 盘片、表面、磁道、扇区
- 柱面：对齐的磁道形成的圆柱
- 记录区域：现代磁盘将磁道分区

**磁盘容量计算**：
```
容量 = (#字节/扇区) × (平均扇区数/磁道) × (#磁道/表面) × (#表面/盘片) × (#盘片/磁盘)
```

**示例计算**：
- 512字节/扇区 × 300扇区/磁道 × 20,000磁道/表面 × 2表面/盘片 × 5盘片
- = 30.72GB

#### 1.5 磁盘访问机制

**访问时间组成**：
```
Taccess = Tavg_seek + Tavg_rotation + Tavg_transfer
```

**各组件说明**：
- 寻道时间：磁头定位到目标柱面，典型3-9ms
- 旋转延迟：等待目标扇区转到磁头下，Tavg_rotation = 1/2 × 1/RPM × 60s/min
- 传输时间：读取目标扇区数据

**示例计算**（7200 RPM，平均寻道9ms，400扇区/磁道）：
- Tavg_rotation = 4ms
- Tavg_transfer = 0.02ms  
- Taccess = 9 + 4 + 0.02 = 13.02ms

**性能对比**：
- 磁盘比SRAM慢约40,000倍
- 比DRAM慢约2,500倍

#### 1.6 逻辑磁盘块与I/O总线

**逻辑磁盘块抽象**：
- 物理扇区映射为逻辑块序列
- 磁盘控制器处理映射
- 支持备用柱面设置

**I/O总线结构**：
- CPU通过I/O桥连接各种设备
- 包括USB控制器、图形适配器、磁盘控制器等

#### 1.7 固态硬盘(SSD)

**SSD结构**：
- Flash翻译层 + Flash内存
- 组织为块(32-128页)和页(512KB-4KB)
- 页级读写，块级擦除
- 约10万次写寿命

**SSD性能特点**：
- 顺序读取：550MB/s，顺序写入：470MB/s
- 随机读取：365MB/s，随机写入：303MB/s
- 顺序访问快于随机访问
- 随机写入较慢（需要块擦除和页面复制）

**SSD vs 旋转磁盘**：
- 优势：无移动部件、更快、更省电、更坚固
- 劣势：有磨损可能、价格更高（2015年约贵30倍）

#### 1.8 存储趋势与CPU-内存差距

**性能差距扩大**：
- CPU速度增长远快于内存和磁盘
- 有效CPU周期时间从1985年166ns降至2015年0.08ns

**存储技术趋势**（1985-2015）：
- SRAM：成本下降116倍，访问时间改善115倍
- DRAM：成本下降44,000倍，容量增长62,500倍
- 磁盘：成本下降3,333,333倍，容量增长300,000倍

## 第二章：局部性原理

### 整体思路
阐述程序访问内存的内在规律——局部性原理，这是缓存技术能够有效工作的理论基础，也是程序员编写高性能代码的关键考量。

#### 2.1 局部性原理定义

**原理核心**：程序倾向于使用最近使用过的地址或邻近地址的数据和指令

**两种局部性**：
- **时间局部性**：最近被引用的项很可能在不久的将来再次被引用
- **空间局部性**：地址相近的项倾向于在时间上相近被引用

#### 2.2 局部性示例分析

**示例代码**：
```c
sum = 0;
for (i = 0; i < n; i++)
    sum += a[i];
return sum;
```

**局部性分析**：
- 数据引用：
  - 顺序访问数组元素（步长1引用模式）→ **空间局部性**
  - 每次迭代引用变量sum → **时间局部性**
- 指令引用：
  - 顺序引用指令 → **空间局部性**  
  - 循环重复执行 → **时间局部性**

#### 2.3 局部性定性评估

**核心技能**：通过查看代码获得其局部性的定性感觉是专业程序员的关键技能

**行优先访问示例**：
```c
int sum_array_rows(int a[M][N]) {
    int i, j, sum = 0;
    for (i = 0; i < M; i++)
        for (j = 0; j < N; j++)
            sum += a[i][j];
    return sum;
}
```
**分析**：具有良好的空间局部性（步长1访问）

**列优先访问示例**：
```c
int sum_array_cols(int a[M][N]) {
    int i, j, sum = 0;
    for (j = 0; j < N; j++)
        for (i = 0; i < M; i++)
            sum += a[i][j];
    return sum;
}
```
**分析**：空间局部性差（步长N访问）

**三维数组优化**：
```c
int sum_array_3d(int a[M][N][N]) {
    int i, j, k, sum = 0;
    for (k = 0; k < N; k++)
        for (i = 0; i < M; i++)
            for (j = 0; j < N; j++)
                sum += a[k][i][j];  // 调整为a[k][i][j]获得步长1访问
    return sum;
}
```

## 第三章：内存层次结构与缓存

### 整体思路
基于存储技术差异和局部性原理，构建多层次的内存体系，通过缓存机制弥合CPU与主存之间的性能鸿沟。

#### 3.1 内存层次结构的理论基础

**硬件软件的基本属性**：
1. 快速存储技术每字节成本更高、容量更小、功耗更大
2. CPU与主内存速度差距持续扩大
3. 良好编写的程序倾向于展现良好的局部性

**这些属性相互补充**，催生了内存层次结构方法

#### 3.2 内存层次结构示例

**典型层次**：
1. L1缓存（SRAM）
2. L2缓存（SRAM） 
3. L3缓存（SRAM）
4. 主内存（DRAM）
5. 本地磁盘
6. 远程二级存储（如Web服务器）

#### 3.3 缓存基本概念

**缓存定义**：较小、较快的存储设备，作为较大、较慢设备数据子集的暂存区

**内存层次结构基本原理**：
- 对于每个级别k，较快较小的设备作为较慢较大设备（级别k+1）的缓存
- 由于局部性，程序访问级别k数据的频率高于级别k+1
- 因此级别k+1的存储可以更慢，从而更大、每比特更便宜

**核心思想**：内存层次结构创建了大的存储池，成本接近底部的廉价存储，但以顶部快速存储的速率向程序提供数据

#### 3.4 通用缓存概念

**基本结构**：
- 缓存：较小、较快、较贵的存储器，缓存块的子集
- 内存：较大、较慢、较便宜的存储器，划分为"块"
- 数据以块大小传输单位复制

**缓存命中**：
- 请求的数据块在缓存中
- 示例：请求块14，缓存中包含该块

**缓存未命中**：
- 请求的数据块不在缓存中
- 块从内存获取并存储在缓存中
- 涉及放置策略（决定块存放位置）和替换策略（决定驱逐哪个块）

#### 3.5 缓存未命中类型

**冷（强制性）未命中**：
- 因为缓存为空而发生

**冲突未命中**：
- 级别k+1的块被限制在级别k块位置的小子集中
- 当级别k缓存足够大，但多个数据对象都映射到同一级别k块时发生
- 示例：引用块0,8,0,8,0,8...每次都会未命中

**容量未命中**：
- 当活动缓存块（工作集）大于缓存时发生

#### 3.6 内存层次结构中的缓存示例

| 缓存类型 | 缓存内容 | 缓存位置 | 延迟(周期) | 管理方 |
|---------|----------|----------|------------|--------|
| 寄存器 | 4-8字节字 | CPU核心 | 0 | 编译器 |
| TLB | 地址转换 | 片上TLB | 0 | 硬件MMU |
| L1缓存 | 64字节块 | 片上L1 | 4 | 硬件 |
| L2缓存 | 64字节块 | 片上L2 | 10 | 硬件 |
| 虚拟内存 | 4-KB页 | 主内存 | 100 | 硬件+OS |
| 缓冲区缓存 | 文件部分 | 主内存 | 100 | OS |
| 磁盘缓存 | 磁盘扇区 | 磁盘控制器 | 100,000 | 磁盘固件 |

#### 3.7 总结

**核心结论**：
- CPU、内存和大容量存储之间的速度差距持续扩大
- 良好编写的程序展现称为局部性的属性
- 基于缓存的内存层次结构通过利用局部性来弥合这一差距

## 补充技术细节

### DRAM组织与操作

**DRAM结构**：
- d×w DRAM：dw总位，组织为d个大小为w位的超单元
- 16×8 DRAM芯片：16行×4列，每个超单元8位

**读取DRAM超单元流程**：
1. 行访问选通(RAS)选择行，该行从DRAM阵列复制到行缓冲区
2. 列访问选通(CAS)选择列，超单元从缓冲区复制到数据线

**内存模块**：
- 由多个DRAM芯片组成
- 示例：64MB内存模块，由八个8M×8 DRAM组成

### 增强型DRAM

**发展历程**：
- 基本DRAM单元自1966年发明以来未变
- 1970年由Intel商业化

**增强类型**：
- SDRAM：使用常规时钟信号代替异步控制
- DDR SDRAM：双倍数据率，每个周期每个引脚发送两位
  - DDR(2位)、DDR2(4位)、DDR3(8位)
  - 到2010年成为大多数服务器和桌面系统的标准

### CPU时钟速率发展

**历史趋势**：
- 1985-2003年：时钟速率快速增长
- 2003年后：遇到"功耗墙"，转向多核心设计

**具体数据**：
- 1985：6MHz（166ns周期）
- 2003：3,300MHz（0.30ns周期）  
- 2015：3,000MHz，4核心（有效周期时间0.08ns）

**性能提升**：从1985到2015年，有效周期时间改善约2,075倍
